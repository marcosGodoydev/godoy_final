# TecnoShop — Ecommerce (Trabajo Final)

Ecommerce desarrollado en **React** (Vite + React Router).

## Páginas
- **Home** (`/`): listado de productos.
- **Detalle de producto** (`/producto/:id`): nombre, precio, stock y código.
- **Registro** (`/registro`): formulario de registro (solo maquetado).
- **Login** (`/login`): email y contraseña (solo maquetado).

Los productos salen de un mock de datos en `src/data/products.js`.

## Cómo ejecutarlo
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
